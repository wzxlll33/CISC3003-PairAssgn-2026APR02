Project Summary

CISC3003 Web Programming - Pair Assignment

1. Project Overview

Pair Studio is a freelance web design agency website created for the CISC3003 Web Programming course. The website showcases our skills, services, and portfolio projects.

2. Site Structure

  1. Home (index.html) Landing page with hero section, team introduction, and services preview
  2. Profile (profile.html) Detailed information about both team members and contact form
  3. Summary (summary.html) Project documentation and technical overview
  4. Showcase (showcase.html) Portfolio projects, accomplishments, and business offers
  5. Qualification (qualification.html) Certifications, skills, and professional credentials

3. Technologies Used

Frontend Technologies

  • HTML5 - Semantic markup and structure
  • CSS3 - Styling, animations, and responsive design
  • JavaScript - Interactive features and form validation

Development Tools

  • Eclipse IDE for Web Development
  • Chrome DevTools for debugging
  • Git for version control

4. Key Features Implemented

  1. Responsive Design Mobile-first approach with breakpoints at 768px and 1024px
  2. Interactive Navigation Hamburger menu for mobile devices with smooth animations
  3. Contact Form Functional form with validation and user feedback
  4. Portfolio Showcase Project demos with live preview links
  5. CSS Animations Hover effects, counters, and scroll-triggered animations
